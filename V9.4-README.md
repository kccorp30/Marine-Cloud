# KCC Marine Cloud V9.4 — Estimate / Upload / Luz recovery

## Fixed

1. Estimate email/customer portal regression
   - Production error was the DB constraint `organization_invitations_intended_role_check` rejecting `customer`.
   - Added an independent hotfix migration that explicitly includes `customer`.
   - This migration does not depend on the rest of the V9 credentials migration being present.

2. Profile photo / company logo uploads
   - Source image limit raised from 2 MB to 12 MB.
   - Next.js Server Action body limit raised to 12 MB.
   - Browser pre-processing now compresses larger JPEG/PNG/WebP images before upload.
   - Sharp input pixel ceiling raised for modern phone photos, while final persisted images remain small WebP assets.

3. Luz estimate concierge
   - Luz is no longer only a passive "polish" message.
   - It can generate a customer note from an empty field using the actual estimate context.
   - It can improve an existing note.
   - Tone controls: Professional / Warm / Concise.
   - Draft can be applied or regenerated.
   - Output language follows the current UI locale (EN/ES).
   - Prompt is constrained not to invent prices, warranties, dates, diagnostics, completion claims or promises.

## Required database deployment

Apply:

`supabase/migrations/20260916011500_customer_invitation_role_hotfix.sql`

If the migration is not applied, customer portal creation from an estimate will continue to be rejected by the old production DB constraint.

## Environment

Luz requires `ANTHROPIC_API_KEY` on the server. Existing email delivery still requires the current Resend configuration.

## Smoke tests

1. Send estimate to a customer without an active portal profile.
2. Verify customer invitation is created and estimate email is delivered.
3. Upload a 5–10 MB JPEG as user profile photo.
4. Upload a 5–10 MB JPEG/PNG as company logo.
5. In a draft estimate with an empty Customer Message, click Generate with Luz.
6. Apply the draft, save details, preview email, then send.
7. Repeat with an existing rough note and each Luz tone option.
