# KCC Marine Cloud V9.8 — Phase 4: Motion + Attention System

## Goal
Turn notifications from passive badges into a role-scoped operational attention system while keeping the current RLS/recipient model intact.

## What changed

### 1. Global Attention Center
- `action_required`, `urgent`, and `critical` unread notifications now surface globally below the fixed header.
- Highest-severity item wins; lower-priority pending items are counted behind it.
- The banner remains visible until the user marks it seen or acknowledges it.
- Supported entities deep-link directly to the work order, estimate, invoice, vessel, service request, conversation, or KCC assistance request.
- Realtime INSERT/UPDATE subscription remains explicitly filtered by `recipient_user_id`.

### 2. Realtime sound feedback
- Central WebAudio sound service is used for new recipient-scoped notifications.
- Different pulse patterns for info/action/urgent/critical/KCC assistance.
- Audio failures never break UI.
- AudioContext is closed after playback.

### 3. Per-user alert preferences
New table:
- `public.notification_preferences`
- `sound_enabled`
- `motion_enabled`

RLS: each authenticated user can only read/insert/update their own row.

Preferences are available inside the notification drawer and Attention Center page. They persist across devices/accounts instead of only relying on browser state.

Migration was also applied to production Supabase and is included at:
- `migrations/271_notification_preferences.sql`
- `supabase/migrations/20260916080000_notification_preferences.sql`

### 4. Premium Notification Center
`/notifications` is now an actual Attention Center:
- Luz hero/presence
- action-required and urgent counters
- All / Unread / Action Required filters
- richer severity cards
- direct entity CTA
- inline mark-read / acknowledge
- persistent unread indicator
- sound/motion preferences

### 5. Motion system
Pure CSS motion was intentionally used instead of adding another runtime dependency.
- staged command-screen entrance
- attention-banner entrance
- realtime toast entrance
- beacon pulse
- premium CTA shine
- hover depth
- severity glow

Motion respects:
- saved `motion_enabled`
- `prefers-reduced-motion`

### 6. Realtime behavior
Info notifications appear as short-lived premium toasts.
Action-required / urgent / critical events do **not** disappear as toasts; they enter the persistent global Attention Center instead.

This avoids duplicate noisy UI while making important work impossible to miss.
